Docker self-host

Any Linux server with Docker Compose v2.

git clone https://github.com/CodesbyFebin/Open-Founder
cd Open-Founder && cp .env.example .env
docker compose up -d

One-line install

curl -fsSL https://codesbyfebin.github.io/Open-Founder/install.sh | sh

Then open http://localhost:3000. Subcommands: up, down, logs, update.

Builds come from GitHub Releases. If a button returns 404, the first release hasn't been published yet. Desktop and Android builds are thin shells around your server, and full offline storage inside them is still in progress. See the installation guide.
