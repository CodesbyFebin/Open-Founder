# Contributing

1. Fork, then create a branch: `git checkout -b feat/x`
2. `npm install && npm run typecheck && npm test`
3. Keep providers behind adapters, and keep money in paise.
4. Open a PR with a clear description.

Good first areas: the IMAP watcher, the Razorpay/Cashfree/PhonePe adapters, the GSTR-1 JSON export, the login UI and translations.

Only contribute code you have the right to license under MIT. Please don't submit copied proprietary code.
