# FAQ

**Is it really free?** Yes. It's MIT licensed and you host it yourself. Your providers (Meta WhatsApp, AI APIs, hosting) may charge you.

**Zero-fee UPI, how?** Customers pay your UPI ID directly. There's no gateway in between, so there's no MDR. You verify payments through bank alerts or webhooks.

**Does it file GST returns?** Not yet. It computes tax and summaries, and you file on the GST portal.

**Does the app work offline?** The web app queues sales offline. The mobile and desktop apps need your server to load.

**Download button returns 404?** The first GitHub Release hasn't been published yet. Check the Releases page.

**Windows warns about the installer?** It isn't code-signed yet. Choose More info → Run anyway.

**Where's my data?** In your own PostgreSQL database.
